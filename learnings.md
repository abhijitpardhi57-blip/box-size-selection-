# What I Learned From This Assignment

Working on this assignment was a valuable learning experience for me. It was not just about writing code, but also about understanding requirements, solving problems logically, and making sure the solution worked correctly.

## Understanding Requirements

One of the biggest lessons I learned was the importance of reading and understanding requirements carefully before starting development. I realized that a small misunderstanding in requirements can lead to incorrect implementation and extra rework later.

## Breaking Down a Complex Problem

At first, the packing problem seemed complicated, but I learned how to break it into smaller tasks. Instead of trying to solve everything at once, I focused on individual parts such as product dimensions, box selection, item placement, and validation.

This approach made the problem much easier to handle.

## Django Development

While building this project, I gained more confidence working with Django. I learned how to:

- Create and organize Django applications
- Build API endpoints
- Handle JSON requests and responses
- Validate user input
- Structure backend code in a clean and maintainable way

## Algorithm Design

The most interesting part of the assignment was implementing the packing logic.

Through this process, I learned:

- How to think about dimensions and spatial constraints
- How to compare multiple possible solutions
- How to apply business rules when selecting the best box
- How to handle edge cases that may not be obvious at first

It improved my logical and problem-solving skills.

## Importance of Testing

This assignment taught me that writing code is only half of the job. Testing is equally important.

I learned how to:

- Write unit tests
- Verify expected results
- Test different scenarios
- Catch mistakes early
- Build confidence in the solution

I also learned that assumptions should always be validated through testing rather than trusted blindly.

## Debugging and Verification

While working on the assignment, I discovered that some assumptions were incorrect after checking the actual dimensions and test results.

This taught me that:

- Debugging is a normal part of development
- Careful verification is extremely important
- Even small details can affect the final outcome
- It is always worth reviewing results before considering a task complete

## Documentation

I learned how important good documentation is for any project.

Writing documentation helped me think more clearly about:

- Project structure
- Design decisions
- Usage instructions
- Testing process
- Assumptions and limitations

Good documentation makes a project easier for others to understand and maintain.

## Using AI Effectively

Another important lesson was learning how to use AI as a development assistant.

I learned that AI can help with:

- Generating initial code
- Suggesting ideas
- Reviewing logic
- Creating tests and documentation

However, I also learned that AI-generated code should always be reviewed, tested, and verified by the developer before being accepted.

## Key Takeaway

The biggest lesson from this assignment is that software development is much more than writing code. It involves understanding requirements, designing solutions, testing thoroughly, debugging issues, documenting decisions, and continuously improving the implementation.

Overall, this assignment helped me improve my skills in Django development, API design, algorithmic thinking, testing, debugging, documentation, and professional software development practices.
